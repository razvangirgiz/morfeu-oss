# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good intent, and keep discussions about the work. Harassment, insults and personal attacks are not tolerated in issues, pull requests or any other project space.

Report unacceptable behaviour privately to the maintainer through the email on their GitHub profile. Reports are handled confidentially, and maintainers may remove comments, lock threads, or ban participants who break these rules.
